# AShareRadar Windows Package

The supported distribution is the directory package generated by
`build-package.ps1`. The single EXE/Inno Setup flow is deprecated and is kept
only for historical reference.

## Build the package

The command always publishes the current source tree before assembling the
package. It does not reuse `artifacts\verify-*` output directories.

```powershell
powershell -ExecutionPolicy Bypass -File .\packaging\windows\build-package.ps1 `
  -PackageKind Full `
  -HistoricalDuckDbPath "E:\AShareRadar\data\ashare.duckdb" `
  -RuntimeDataRoot "E:\AShareRadar\data"
```

Output:

```text
%USERPROFILE%\Documents\AShareRadar\build\publish\
%USERPROFILE%\Documents\AShareRadar\packages\AShareRadar-Setup\
%USERPROFILE%\Documents\AShareRadar\packages\AShareRadar-Full-YYYYMMDD.zip
```

The source repository remains separate from generated output and package
output. `-RuntimeDataRoot` copies the complete runtime data tree while still
filtering logs, caches, and lock files.

The directory package installs Python dependencies into
`tools\eastmoney_quant\.python_packages`. The build requires the external
`gm.api` SDK supplied by the EastMoney/掘金 terminal; it is not replaced by a
fallback provider.

## Install for end users

Extract `AShareRadar-Full-YYYYMMDD.zip`, then run `install.ps1`. When the E:
drive exists, the default directory is `E:\AShareRadar`; otherwise it falls
back to `%LOCALAPPDATA%\AShareRadar`. Pass `-InstallDir` to choose another
directory.

## Directory package install

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Default install directory when the E: drive exists:

```text
E:\AShareRadar
```

To install with an SDK token:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Token "<EASTMONEY_QUANT_TOKEN>"
```

The token is written to `config\appsettings.local.json` under the install
directory. It is not persisted to the Windows user environment. The same file
can be moved with the application directory when migrating to another machine.

Skip desktop shortcut creation:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -NoShortcut
```

The installer rewrites `app\service\appsettings.json` so all data and script paths point to the install directory.

## Start and Stop

```powershell
powershell -ExecutionPolicy Bypass -File "E:\AShareRadar\start-ashare-radar.ps1"
powershell -ExecutionPolicy Bypass -File "E:\AShareRadar\stop-ashare-radar.ps1"
```

## Upgrade

```powershell
powershell -ExecutionPolicy Bypass -File .\upgrade.ps1
```

Upgrade replaces `app`, `tools`, and package scripts, then rewrites config. Existing `data\runtime` is preserved.

## Doctor

```powershell
powershell -ExecutionPolicy Bypass -File "E:\AShareRadar\doctor.ps1"
```

Doctor checks executables, data files, Python, token, tools, and the local service health endpoint.

## Uninstall

```powershell
powershell -ExecutionPolicy Bypass -File "E:\AShareRadar\uninstall.ps1" -InstallDir "E:\AShareRadar"
```

Keep data while removing application files:

```powershell
powershell -ExecutionPolicy Bypass -File "E:\AShareRadar\uninstall.ps1" -InstallDir "E:\AShareRadar" -KeepData
```
